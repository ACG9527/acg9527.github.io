用 Termux + Hugo 在手机上搭建个人博客

Mar 04, 2026
loading... 次
阅读时长: 3 分钟

在这个信息爆炸的时代，拥有一个完全属于自己的博客，不仅是技术能力的体现，更是记录思考、分享知识的绝佳方式。今天，我将带你一步步在手机上，利用 Termux 和 Hugo，从零开始搭建一个属于你自己的静态博客。

一、为什么选择 Termux + Hugo？

  • 完全掌控：从代码到部署，每一步都由你决定，告别平台束缚。
  • 随时随地：掏出手机就能写文章、改代码，灵感来了就记录。
  • 高效生成：Hugo 是目前最快的静态网站生成器，几毫秒就能生成整个站点。
  • 免费部署：可以轻松部署到 GitHub Pages 等平台，零成本上线。

二、准备工作：安装 Termux 和必要软件

首先，我们需要在手机上安装 Termux，这是一个强大的 Android 终端模拟器。

  1. 安装 Termux：从 F-Droid 或 GitHub 下载并安装 Termux。
  2. 更新软件源：打开 Termux，执行以下命令更新软件包列表： 
    1

    pkg update && pkg upgrade
  3. 安装 Hugo 和 Git： 
    1

    pkg install hugo git

三、创建你的第一个 Hugo 站点

软件安装好后，我们就可以开始创建博客了。

  1. 创建站点：在 Termux 中，执行以下命令创建一个新的 Hugo 站点，我将其命名为 my_blog： 
    1

    hugo new site my_blog
  2. 进入站点目录： 
    1

    cd my_blog
  3. 选择并安装主题：Hugo 本身不提供默认主题，我们需要选择一个喜欢的主题。这里以热门的 hugo-theme-stack 为例： 
    1

    git clone https://github.com/CaiJimmy/hugo-theme-stack.git themes/hugo-theme-stack
  4. 启用主题：将主题的示例配置文件复制到站点根目录，作为我们的配置起点： 
    1

    cp themes/hugo-theme-stack/config.yaml .

四、开始写作：发布你的第一篇文章

现在，你的博客框架已经搭好了，是时候写第一篇文章了。

  1. 创建文章：使用 Hugo 命令创建一篇新文章： 
    1

    hugo new post/我的第一篇博客.md
    这个命令会在 content/post/ 目录下生成一个 Markdown 文件。
  2. 编辑文章：你可以使用 nano 或 vim 等编辑器打开并编辑这篇文章： 
    1

    nano content/post/我的第一篇博客.md
    在文件中，你可以用 Markdown 语法尽情书写你的想法。
  3. 本地预览：写完文章后，启动 Hugo 内置的服务器，在手机浏览器中预览效果： 
    1

    hugo server -D
    然后在手机浏览器中访问 http://localhost:1313/，你就能看到你的博客了！

五、部署上线：让全世界看到你的博客

博客在本地预览没问题后，我们就可以将它部署到互联网上了。这里我们使用 GitHub Pages。

  1. 创建 GitHub 仓库：在 GitHub 上创建一个新的仓库，命名为 你的用户名.github.io。
  2. 初始化 Git 仓库：回到 Termux，在你的博客目录下初始化 Git： 
    1
2
3

    git init
git add .
git commit -m "Initial commit"
  3. 关联远程仓库：将本地仓库与你在 GitHub 上创建的仓库关联： 
    1

    git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
  4. 推送代码：将你的博客代码推送到 GitHub： 
    1

    git push -u origin main
  5. 启用 GitHub Pages：在 GitHub 仓库的设置中，找到 Pages 选项，将源设置为 main 分支的根目录。

稍等几分钟，访问 https://你的用户名.github.io，你的博客就正式上线了！

六、结语

用手机搭建博客，听起来像是天方夜谭，但通过 Termux 和 Hugo，这一切都变得触手可及。这不仅是一个技术实践，更是一种生活方式的改变——你不再是信息的被动消费者，而是主动的创造者和分享者。

现在，就从你的第一篇博客开始，记录下你的思考和成长吧。
